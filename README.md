# Warm-Up Video Maker

Makes 15-minute kids' warm-up videos for a wall projector. A cartoon character does each move, there's real footage behind it, and the music, sound effects and voice are all on the beat (120 BPM).

| Version | Command | Output file |
|---|---|---|
| Back to School (cartoon kid) | `python make_video.py school` | `output/BackToSchool_WarmUp_15min.mp4` |
| Hana's Japan Adventure (anime girl) | `python make_video.py japan` | `output/Hana_Japan_WarmUp_15min.mp4` |

The videos are 720p and about 100–200 MB each.

---

## Windows: first-time setup (once)

1. **Install Python 3.11 or newer** from https://www.python.org/downloads/
   On the first installer screen, tick **"Add python.exe to PATH"**.
2. **Install ffmpeg.** Open *Command Prompt* and run:
   ```
   winget install Gyan.FFmpeg
   ```
   Then close Command Prompt and open it again.
3. **Get this folder.** Either `git clone` it, or download the ZIP from GitHub (green **Code** button → **Download ZIP**) and unzip it.
4. **Double-click `setup_windows.bat`.** It installs everything the renderer needs, including a hidden Chrome used for drawing frames.

## Make a video

Double-click **`make_school.bat`** or **`make_japan.bat`**.

Or, in Command Prompt inside this folder:
```
python make_video.py school
python make_video.py japan
python make_video.py japan --workers 8     # use more CPU cores = faster
python make_video.py japan --preview 30 300 600   # just a few still images to check the look
```
The first run downloads the free stock clips (about 400 MB) into `footage/`. A faster PC finishes sooner; each worker uses about one CPU core.

## Play it on the projector (full screen, repeats forever)

- **Windows:** double-click **`player/Start_Warmup.bat`**. To choose the video, open the file in Notepad and change the `VIDEO=` line.
- **Mac:** double-click `player/Start_Warmup_Mac.command`.
- **To close it:** press **Alt + F4** (Windows) or **Cmd + Q** (Mac).
- **Start it automatically when the PC turns on:** press `Win + R`, type `shell:startup`, and put a shortcut to `Start_Warmup.bat` in the folder that opens.

## Change the content

Everything is in `timelines/school.js` and `timelines/japan.js`. Each part has these settings:

| Setting | What it does |
|---|---|
| `cue` / `story` | Text shown on screen |
| `say` | What the voice says, as `[seconds, "text"]` |
| `move` | The exercise (see the list below) |
| `clip` | The Mixkit footage number shown behind the character |
| `dur` | How long the part lasts, in seconds |

**Moves:** `wave reach run highknees jump tuckjump hop squat starjump freeze reachside frog punch kick skater climb fly balance armcircles toetouch sidestretch breathe rest`

**After editing the text, rebuild the sound:**
```
python make_video.py school --new-audio
```
On Windows, new voice lines use the free Microsoft voices (needs internet). The voice lines that come with the repo are already in `voice_cache/`.
